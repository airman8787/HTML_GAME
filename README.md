# 月蝕奏鳴曲 ／ ECLIPSE SONATA

ブラウザで遊べるオリジナルの縦スクロール弾幕シューティングです。全5面と隠しボス。

## ▶ 遊ぶ

**https://airman8787.github.io/HTML_GAME/**

インストール不要。PC でもスマホでも遊べます。

## 操作

| | PC | スマホ |
|---|---|---|
| 移動 | 矢印キー / WASD | ドラッグ |
| 射撃 | Z / Space | 自動 |
| 低速移動（当たり判定を表示） | Shift | — |
| ボム（被弾直後でも有効） | X | 画面下の「ボム」ボタン |
| 一時停止 | Esc / P | 「一時停止」ボタン |

音はタイトル画面でどこかをクリックするか、右上の「音」ボタンで鳴り始めます。

## 遊び方のヒント

- 難易度は 初級・標準・上級・極夜 の4段階。初めてなら「標準」がおすすめです
- 初級と標準では「自動ボム」、初級では「オート」操作を画面下のボタンで使えます（ON のスペルでは音譜を獲得できません）
- 面の開始・中ボス撃破後・ボス戦前に自動でセーブされ、タイトルから続きを遊べます
- スペルカードを被弾せずに突破すると「音譜帳」に収録されます
- 最終ボスをボムを使わずに倒すと……？

## 自分の PC で遊ぶ

`index.html` をダウンロードしてブラウザで開くだけで動きます。
